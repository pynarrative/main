However, you can also configure your own customizable template

How does it work?

  1. Once you've downloaded your favourite template...

  2. Open the directory you've downloaded the file in, cut the .py file and paste it into the following directory: pynarrative > src > pynarrative > templates > mytemplates

  3. On your python script or on your notebook write:

    from pynarrative.templates.mytemplates.templateName import templateName

  4. Try it and enjoy!

    Important! Please note that the font-family pre-set in the template you chose will be applied to your chart only if you have it already available on your computer, otherwise python will use a fallback font family. However, if you are using a Notebook to create your data story, as we recommend, you can use the Jupyter Notebook %%html special cell.
    Go on Google Fonts and find the font that is used in the template. Then click on Get font, on Get embed code, then on @import. Finally, click on Copy code. In a new cell located before the data story you're working on, write:

    %%html

    And paste what you had copied from Google Fonts.

    You should have gotten something like this:

    %%html <style> @import url('https://fonts.googleapis.com/css2?family=the_font_you_chose:ital,wght@0,300..800;1,300..800&display=swap'); </style>

    And after that:
